Версия 25.9.11 для роутеров:
- Keenetic Skipper 4G (KN-2910)
- Keenetic 4G (KN-1212)

Эти роутеры несовместимы с официально компилируемыми ядрами xray и для них требуются ядра из репозитория Entware, либо собранные энтузиастами. Здесь выложены несколько таких ядер в сжатом виде. К сожалению, их версии могут быть не самыми последними, но, это лучше, чем ничего

Комментарий от пользователя, если захотите собрать ядро сами:
- Нужно добавить в компилятор GOMIPS=softfloat, с ним соберется и будет работать на KN-2910 и KN-1212, потому что MIPS24kc не имеют fpu, эмуляция програмно позволяет это обходить кодом "softfloat"
